# Contributing to Project Lattice

Project Lattice is a collaborative student engineering project.

Contributions can include research, hardware development, firmware, software, experiments, testing and documentation.

## Before Starting

Before beginning work:

1. Check the relevant GitHub Issues.
2. Make sure the task is not already being worked on.
3. Read the relevant project documentation.
4. Ask questions if the requirements are unclear.

## Working on a Task

Each significant piece of work should normally have a GitHub Issue.

Examples:

- Hardware research
- Software development
- Firmware development
- Experiments
- Testing
- Documentation

Work should be connected to the relevant issue so that the team can see what is being developed.

## Branches

Do not normally make changes directly to the `main` branch.

Create a separate branch for your work.

Example:

```text
research/microphone-options
feature/tdoa-processing
feature/object-detection
experiment/microphone-spacing
