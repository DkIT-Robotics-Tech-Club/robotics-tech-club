# Project Lattice - Software

This folder contains the software developed for Project Lattice.

The software will support acoustic signal processing, computer vision, data analysis, sensor fusion, testing and system visualisation.

## Main Areas

### Signal Processing

Software for processing microphone data and investigating:

- Signal filtering
- Signal analysis
- Time Difference of Arrival (TDOA)
- Direction estimation
- Acoustic classification

### Computer Vision

Software for processing camera data and investigating:

- Image processing
- Object detection
- Object tracking
- Visualisation

### Sensor Fusion

Software for combining information from the acoustic and visual sensing systems.

This may include:

- Combining direction estimates
- Comparing acoustic and visual measurements
- Target association
- Combined tracking

### Data & Analysis

Software and scripts used for:

- Recording data
- Processing experimental data
- Analysing results
- Generating plots and measurements
- Comparing different approaches

## Development Approach

Software should be developed in small, testable components.

Where practical:

- Keep processing modules separate.
- Document important algorithms.
- Record dependencies.
- Test individual components before integration.
- Keep experimental code separate from stable implementations.
