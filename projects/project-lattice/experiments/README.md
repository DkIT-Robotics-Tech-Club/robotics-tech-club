# Project Lattice - Experiments

This folder contains experiments carried out during the development of Project Lattice.

Experiments should be used to test assumptions, compare different approaches and measure how well individual parts of the system perform.

## Purpose

The aim of experimentation is to answer engineering questions using measurements rather than assumptions.

Experiments may investigate:

- Acoustic sensing
- Microphone-array configurations
- Signal processing
- TDOA
- Direction estimation
- Computer vision
- Object detection
- Visual tracking
- Sensor fusion
- Target tracking
- System performance

## Experiment Structure

Each significant experiment should document:

- Objective
- Question being investigated
- Hardware used
- Software used
- Test setup
- Procedure
- Measurements
- Results
- Problems encountered
- Conclusion
- Recommended next steps
