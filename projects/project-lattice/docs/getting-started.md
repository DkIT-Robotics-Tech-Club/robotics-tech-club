# Project Lattice - Getting Started

Welcome to Project Lattice.

Project Lattice is a student engineering project focused on developing a multimodal sensing and tracking demonstrator using acoustic sensing and computer vision.

You do not need to be an expert to contribute.

## Before You Start

1. Read the Project Lattice overview.
2. Read the system architecture.
3. Read the contribution guidelines.
4. Look through the open GitHub Issues.
5. Choose an area that interests you.

## Areas of Work

Students may contribute to areas including:

- Acoustic sensing
- Microphone arrays
- Signal processing
- TDOA
- Computer vision
- Object detection
- Visual tracking
- Embedded systems
- Software
- Hardware
- Mechanical design
- Experiments
- Testing
- Documentation

## Choosing a Task

Open GitHub Issues are used to track project tasks.

Look for issues labelled:

`project-lattice`

and choose an issue that matches your interests and experience.

If you are unsure which task to choose, ask the project team.

## Working on a Task

Once you have selected a task:

1. Confirm that nobody else is already working on it.
2. Create a branch for your work.
3. Carry out the research or development.
4. Document your work.
5. Test your changes where appropriate.
6. Open a Pull Request.
7. Wait for review before merging.

See `CONTRIBUTING.md` for the full workflow.

## Research Tasks

Research tasks should produce useful information for the project rather than simply collecting links.

Where appropriate, compare multiple options and consider:

- Performance
- Cost
- Availability
- Compatibility
- Power requirements
- Ease of integration
- Limitations

Research findings should be documented in the appropriate project documentation.

## Experiments

Experiments are used to answer engineering questions through testing and measurement.

Record:

- Objective
- Question
- Setup
- Procedure
- Measurements
- Results
- Problems
- Conclusion
- Next steps

See:

`experiments/README.md`

## Testing

Formal tests are used to determine whether the system meets its requirements.

See:

`tests/README.md`

## Ask Questions

You are not expected to know everything before starting.

If something is unclear, ask the team rather than making assumptions that could affect the project.

## Keep Your Work Documented

The goal is not only to build the system but also to leave behind documentation that allows another student to understand and continue the work.

## Current Project Stage

Project Lattice is currently in the research and planning stage.

Initial work is focused on understanding the hardware, software and system requirements before major purchasing or construction decisions are made.
