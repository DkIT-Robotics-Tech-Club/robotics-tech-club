## 2. Project Overview

Explain the overall concept of Project Lattice.

The project combines acoustic sensing and computer vision to investigate how different sensing methods can be used for detection, direction estimation and tracking.

The acoustic system will investigate microphone arrays, signal processing and TDOA-based direction estimation.

The computer vision system will investigate camera-based object detection and visual tracking.

The longer-term goal is to investigate how information from both sensing systems can be combined to improve tracking performance.

The system will be developed and tested incrementally throughout the project.
